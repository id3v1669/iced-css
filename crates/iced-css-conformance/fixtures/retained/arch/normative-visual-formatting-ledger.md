remove parsing of position:fixed. References to other media do not broaden targets.

Appendix E ledger. Its seven-phase overview is not a second contradictory paint
algorithm. Q268 preserves actual fixed-auto contexts and the explicit property
creation rule. Other future stacking triggers remain outside the CSS2.2 grammar.

§9.10's inline-effect prose says override; its property grammar and value definition
say bidi-override. Use bidi-override and reject bare override. This is a recorded
source reconciliation. Author guidance about limiting bidi overrides is not an
instruction to ignore valid author declarations under this project's CSS-wins rule.
Conditional HTML/DTDs do not assign fictitious HTML attributes to iced sources.

that algorithm does not enable CSS isolation or modern authored bidi keywords.

## Delegated policy choices and remaining dependencies

Select the first permitted clearance algorithm: max(clear-lowest-float amount,
preserve-hypothetical-top amount). Negative and zero clearance remain possible;
clearance existence and magnitude are separate state. For same-BFC float avoidance
by a table/replaced/new-BFC block, preserve its category-computed width and try
adjacent placement only if that width fits; otherwise clear below the relevant
preceding floats. Do not take the optional arbitrary width reduction. Its precise
static-position/width interaction still needs §10's extraction.

Other undefined cases (relative table-internal positioning, negative-margin float
placement, root list-item choice, percentage cycles) remain explicit policy work.
Root static/float-none permissions must not be silently chosen through native
widget limitations. Clearance, anonymous boxes, bidi and BFC geometry assertions
remain unrun; the chapter10 size/line-height solvers and text/table algorithms are
required dependencies. This extraction does not close N-CLAUSES.
