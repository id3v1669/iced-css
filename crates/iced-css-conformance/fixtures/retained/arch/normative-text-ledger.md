## Scope and cross-clause review

§16.3 introduces decoration subsections without an extra standalone algorithm.
§16.6.2 is an explicit bidi/whitespace example; do not derive an independent
universal two-space oracle from its particular markup. Other marked examples
illustrate the recorded rules. §16.6.3's combining sentence uses should and its
cross-element first-letter example illustrates that recommendation. Keep this
force distinct from the selector's mandatory applicable first-letter rules.

The decoration visibility note identifies an undefined visible-child case under
a hidden decorated ancestor; it does not select a CSS3 resolution. Constant line
thickness/color still applies to the defined propagation cases. The optional blink
exemption invokes UAAG as an example of satisfying a checkpoint, not incorporation
of every UAAG requirement. See the invocation register for exact reference scope.

The control-character paragraph's U+202x wording is broader than only the named
bidi embedding controls, and newer Unicode adds further controls outside that
range. The paragraph alone does not establish the modern character-set mapping.
Reconcile exact controls with approved Unicode17 analysis before implementation;
retain source scalars and diagnostic/source positions throughout normalization.
BCP47 and Unicode casing/word boundaries still require invocation-specific audits.

## Architecture consequences and remaining policies

Preserve a logical source stream, normalized stream, pre-collapse break positions,
collapsed rendering stream and shaped cluster mapping. These are distinguishable
stages, not necessarily five allocated copies. A one-pass per-widget string trim
cannot preserve the required cross-inline collapse and first-letter/combining
relationships. The editor bridge must retain original text for messages/copy and
map visual hit/caret positions through these transformations.

Explicit library choices remain for script-dependent LF conversion, optional
pre-wrap trailing collapse, letter/word spacing algorithms, justification,
capitalization word boundaries, hidden-decoration/table propagation, and additional
newline recognition. Existing approved choices take precedence when matched to
these exact clauses; this extraction does not silently overwrite them. Public
text/editor probes have not executed this ledger or closed Unicode/IME feasibility.
