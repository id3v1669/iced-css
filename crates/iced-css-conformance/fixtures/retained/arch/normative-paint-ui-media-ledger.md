# Normative ledger — painting, visual effects, UI and media

Status: direct retained-source traversal completed locally after the parallel
attempt was interrupted. This ledger covers media.html, colors.html, visufx.html,
zindex.html and ui.html. It records source requirements, definitions, permissions
and explicit undefined cases, not product implementation or conformance tests.

Source baseline: CSS2.2 FPWD12April2016, fingerprinted in
[normative-source-baseline.md](normative-source-baseline.md). Every row includes
an anchor and a direct paragraph/table/step locator. D means normative definition;
R retains the prose's requirement force, including should and may where stated;
S denotes an explicit undefined/scope boundary. Conditional author/HTML/paged
statements retain their conditions rather than imposing an HTML parser on iced.

Common applicability: managed screen sources in all three modes, native targets
and both renderers. Device/source-language exceptions apply only where stated.
Property Media table fields are informative under §7.3 and are not counted as
normative property restrictions. Definition-table rows are split by field; planned
cases must check all alternatives of a referenced grammar or enumeration.

Every record has evidence status specified; implementation unverified. Primary
owners link through the numbered architecture index. Source extraction supplies
requirements to approved contracts and does not by itself approve an unchosen
policy. The named semantic assertions below are planned, not executed tests.
