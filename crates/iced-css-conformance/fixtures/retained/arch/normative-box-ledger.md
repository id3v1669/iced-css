## Region dispositions and source interpretation

- §8.1 definitions and painting ownership: explicit records above. Diagrams and
  descriptive image links illustrate the areas, not separate numeric algorithms.
- §8.2 is an example; no new requirement is derived from its sample HTML or pixels.
- §§8.3–8.5 property fields, value definitions and expansion/painting rules are
  recorded. Marked examples and notes are explanatory. In particular, collapse
  notes summarize consequences, and the note about special UI borders does not
  override this project's CSS-wins contract. Shorthand reset is independently
  owned by the cascade ledger even where the local explanation is in an example.
- §8.3.1 adjacency is a conjunction of eligibility, no separating material and an
  allowed edge pair. Transitive collapsed groups permit an empty chain with
  children to collapse through; the no-in-flow-children pair alone is not the
  whole algorithm. The explanatory note about positioning not affecting other
  boxes does not add an independently specified new layout formula.
- §8.6 is normative and requires visual edge placement. It does not replace
  Appendix E's painting order or fully define inline background positioning.
- §9.9.1 has an internal inconsistency: its explicit auto definition creates a
  context for fixed boxes, whereas its later generic overview and Appendix E
  auto grouping describe descendant escape. Selected interpretation under
  delegated authority: the explicit property rule controls context creation;
  fixed-auto contexts are atomic at level0, like other actual zero-level
  contexts. Apply generic auto descendant escape only to non-context-forming
  boxes. This is an identified reconciliation, not a claim the source is
  internally consistent. No modern property or trigger is imported.
