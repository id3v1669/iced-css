Every row inherits evidence status **specified; implementation unverified**.
Classification is D (normative definition), R (normative requirement, including
lowercase should), P (normative permission/constrained choice), or S (normative
scope/unspecified boundary). A slash indicates explicitly separated clauses in
one closely coupled record, not a change of requirement force. Planned cases are
oracles for future semantic fixtures; none has run against the product.

Applicability defaults to the managed semantic source tree captured from annotated
ordinary iced views, screen, Compile/Manual/Auto, every required native target and
both renderers. Text/formatting rows apply when their explicit eligible content
exists. Conditional HTML/XML/DTD/authoring rows say so; no iced HTML parser or DTD
is inferred. Backend/API limitations do not exclude a row. P records identify CSS
latitude, not a newly selected library policy. Existing user approvals, including
CSS-wins/defaults and source metadata policy, remain binding.

Design progress: the source/matching and cascade direction is approved in
[section 47](architecture-47-source-selectors.md), its
[kernel](source-selector-contract.md), and
[section 49](architecture-49-syntax-cascade.md). This extraction does not approve
new choices. Detailed property interactions and the explicit gaps below remain
unresolved pending their owner's audit. Owner numbers identify one accountable
[roadmap section](remaining-roadmap.md); `+` names cooperation. All rows depend on
CSS22-000030–000035's force/scope rules and source/value definitions as applicable.
