## Source classification and selected scope

About §§1.2,1.3,1.5 and introductory tutorials/design principles are explicitly
informative. About §1.1 describes the relationship to prior CSS editions; it does
not import removed features. Its specimen property table is a documentation
template, not an additional property. Initial, inherited and computed table fields
retain the meanings supplied by their definitions and the cascade chapter.

The selected host parses the five page properties and preserves their cascade,
inheritance and computed values. It does not paginate. Page declarations remain a
separate context and never become element declarations. These are architecture
consequences of the existing parsing/applicability distinction in
[the property inventory](property-inventory.md), not a new printing commitment.
Actual parser and runtime behavior remains unqualified.

The canvas definition does not settle native-window backdrop transparency. Q273
remains pending in [questions](questions.md). Full imported-reference coverage,
source discrepancies and cross-clause interactions remain open.
